# n8n Automation Portfolio — Brandon Orjuela

AI-powered workflows built to automate Customer Experience operations.

## Workflows

### 1. Feedback Users Automation
Automates incoming user feedback from Slack end-to-end.
Connects: Slack → HEX API → OpenAI → Freshdesk
Result: 98% of cases handled without human intervention.

### 2. QA Weekly Report - Auto
Reads QA audit results from Google Sheets every Monday
and generates an automated performance report with
coaching insights sent directly to the CX team on Slack.

### 3. Check Marks n8n
When an agent reacts with ✅ on a Slack message,
the workflow finds all related tickets with the same
number and marks them automatically — eliminating
manual follow-up.

## Stack
n8n · Slack · OpenAI · Freshdesk · HEX · Google Sheets
